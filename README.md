# Minecraft Spawner Plugin

MinecraftSpawnerPlus is a lightweight Minecraft plugin that adds a `/spawn` command for teleporting players to the spawn point of the server's first loaded world. It is a simple Minecraft plugin, Bukkit API plugin, and player teleportation plugin for Minecraft 1.21 servers.

## Install

1. Build or obtain the plugin JAR file.
2. Stop your Minecraft server.
3. Place the JAR file in the server's `plugins` directory.
4. Start or restart the server.
5. Confirm that the plugin loads successfully in the server console.

The plugin uses the main class `com.enderdevelopment.plugin.Main` and declares compatibility with the Minecraft 1.21 server API.

## Use

1. Join the server as a player.
2. Run `/spawn`.
3. The plugin teleports you to the spawn location of the server's first loaded world.
4. A green confirmation message appears after a successful teleport.

The command can only be used by players. Console users and other non-player command senders receive an error message.
